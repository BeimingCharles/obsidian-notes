# 跨模态情感冲突

## 当前理解

文本、语音和视觉可能传递不同的情绪线索。研究需要判断模型是否有效利用这些线索，以及在冲突、缺失或退化条件下如何作出合理判断。

**模态不一致、输入质量差、模型偏置和人类判断歧义需要区分。** 例如，文字“太好了”与失落的语气可以同时清晰且真实；这种冲突可能是理解讽刺的线索。给冲突模态降权不一定就是正确处理。

| 情况 | 例子 | 需要检验的问题 |
|---|---|---|
| 自然的情绪线索冲突 | 文字积极，语气失落 | 冲突表达了什么，目标情绪由哪些证据支持？ |
| 输入质量退化 | 噪声、遮挡、转写错误 | 哪些证据仍可用？ |
| 模态缺失 | 无视频或无音频 | 能否利用剩余证据，是否应承认不确定？ |
| 模型的模态偏置 | 有效的语气/表情被忽视 | 模型是否只利用词义等捷径？ |
| 标注者分歧 | 多人对清晰片段仍有不同判断 | 是否存在合理歧义或混合情绪？ |

## 我的原始整理

以下保留 2026-09-30 对话中提供的阅读初稿；校正版本见五篇文献笔记。

1. 第一篇主要是证明了多模态信号不一致的问题，然后提出了 MoSEAR 进行注意力分配和专家级的模态融合。
2. 第二篇论文是因为存在多模态信息冲突和数据异质性的问题，提出了双流图学习多模态融合。
3. 第三篇论文，语音模型大多是在转写成文本进行分析而不是直接通过语音进行分析，所以提出了 LISTEN 这个评估框架。
4. 第四篇论文是多模态融合的时候，视频信息往往容易被边缘化，所以提出了 CHASE 这个机制。
5. 第五篇论文也是发现跨模态不一致的问题，然后是通过数据集上的构造阶段的数据标注实现，将隐式转化成显式，这样在推理阶段就不用依赖注意力权重机制了。

## 核对后的关键修正

- **CA-MER：** 在受测模型和数据上揭示音频偏置；“验证/揭示”比“证明所有模型存在该问题”更准确。
- **BiGMF：** 核心是模态内上下文与模态间交互的分开学习；图融合中的冲突与自然情绪表达冲突要分别讨论。
- **LISTEN：** 证明的是受测模型的词义主导表现，不能据此断言内部都执行“先转写再分类”的流水线。音频直接输入也可能被模型主要用于提取词义。
- **CHASE：** 主干不重训，路由器仍需训练；干预是冲突感知、逐层/逐头的，不能概括成始终提高视频权重。
- **显式加权：** 提供监督目标并训练权重预测器；推理仍要预测权重，只是不依赖注意力机制或测试标签。

## 可以进一步追问什么

下面是阅读引出的疑问，**尚未确认创新性，也没有实验结果**。

1. 与整体标签更一致，是否总意味着该模态更有用？清晰且有意义的冲突是否可能被降权？
2. 加入真实对话上下文，会改善语气/表情的解释，还是进一步强化文字偏好？
3. 自然冲突、信号退化和人类标注歧义能否在同一数据中可靠地区分？
4. 注意力权重、预测权重和实际任务贡献之间是否一致？删除或替换证据后，预测变化能否支持这种解释？
